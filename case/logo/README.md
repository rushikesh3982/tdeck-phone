([Printables 741124](https://www.printables.com/model/741124-lilygo-t-deck-td1-case)). Its cheek tufts are smoothed
into a plain curve so it matches the cat on her *Alley Chat HT Pocket* case. That also keeps it printable at badge
size (9.4 mm tall).
